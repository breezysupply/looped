# L20 hints (four rungs; rungs 3–4 end independent credit for this attempt)

1. **Boundary.** Three separate truths: the source repository (what was built), the registry (what a tag or digest holds right now) and the GitOps repository (what each environment should run). The cluster is a fourth, and the reconciler's job is to make it agree with the third. For each ticket, decide which of the four disagrees before changing anything.
2. **Evidence source.** `work/ci/runs/<run>/summary.json` and the stage logs; `git -C work/app log --stat`; `ci-local.sh status`, `ci-local.sh verify-tag <tag>`; `reconciler/run.sh --verify-only`; the reconciler's events in `work/reconciler/log.jsonl`; `kubectl … get deploy beacon-staging -o yaml` including `managedFields`; `work/gitops/envs/*/schema.json` and `release.json` of each artifact.
3. **Discriminating check.** Gate: run the failing test alone and read the assertion against the teammate's diff (`git show HEAD`). Drift: compare `kubectl … get deploy beacon-staging -o json` with `git -C work/gitops show HEAD:envs/staging/deployment.json`. Tag: compare the digest the tag resolves to with the digest in `promotions/staging.json`. Rollback: compare the target artifact's schema range with the environment's current schema.
4. **Root cause and fix.** Gate: variant A scoped the idempotency lookup to the request id, so a retry inserts a duplicate key (500); B labels metrics with the raw path (unbounded cardinality); C accepts quoted ports. Revert or fix that commit only. Drift: the reconciler restores git; make lasting changes by commit, or pause with a written reason and remove the pause. Retag: never promote by tag; pull the recorded digest, re-tag it, promote prod `--from staging --approve`. Rollback: 1.4.0 supports schema ≤ 2 and prod is at 3 after a contract migration — refuse; fix forward (e.g. restore status text in 1.5.1) and plan expand/contract next time.
