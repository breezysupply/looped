# Anduril Round 1 — local labs

Local, free companions to the "Anduril Round 1: Networking + AWS Terraform"
path in LOOPED. Nothing here needs an AWS account.

- [`terraform/`](terraform/) — reference, alternative and broken
  configurations for labs T1–T4 and the mocks' Terraform tasks, with
  `validate-all.sh` (real `fmt`/`init`/`validate`, no credentials).
- [`bash/`](bash/) — five Bash exercises (B1–B3 for the path, M1–M2 for the
  mock interviews) with fixtures and deterministic tests:
  `./run-tests.sh starter` tests your work, `./run-tests.sh solution` the
  references.

All scenarios, labs and questions are invented practice, not real Anduril
interview questions.
